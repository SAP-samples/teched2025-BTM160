# BTM160 | Navigating transformations with the integrated toolchain

## Description

This repository contains the material for the SAP TechEd 2025 session called BTM160 - Navigating transformations with the integrated toolchain.  
This session introduces attendees to both theory and hands-on application of navigating transformations with the integrated toolchain (in particular the interplay of SAP Signavio, SAP LeanIX and SAP Cloud ALM).

The learning objectives are:
- WHY: understanding the value of integrated toolchain for transformations
- WHAT: learning the content and scope of the integrated toolchain
- HOW: deep dive into the integrations across the solutions and how data flows / is synchronized
- applying this knowledge hands-on in the product in SAP Signavio, SAP LeanIX, SAP Cloud ALM


## Overview

The hands-on session covers the following topics: 
- Intro to Integrated Toolchain for Transformations (15 mins)
- Case study of fictional company introduction (5 mins)
- Hands-on group work and exercises in an integrated demo environment (90 mins)
- Q&A & Feedback (10 mins)

## Requirements

The requirements to follow the exercises in this repository are:
- You will need access to computer / laptop
- You will be assigned in groups to collaborate together as team
- You will receive demo user and passwords to access the integrated demo environment
- You will answer questions via a forms
